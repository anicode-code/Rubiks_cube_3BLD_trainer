# Speffz Lab — 3BLD Trainer PWA

A React + Vite progressive web app for practicing Speffz sticker recognition.

## Requirements
- Node.js 20 or newer (npm is included with Node.js)
- A modern browser

## Run locally
1. Extract/open this project folder in your editor.
2. Open a terminal in the folder containing `package.json`.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build and preview
- `npm run build` creates the production app in `dist/`.
- `npm run preview` serves the production build locally for testing.
- Deploy the contents of `dist/` to a static HTTPS host. HTTPS is required for install/offline behavior on deployed sites (localhost is treated as secure for development).

## Install as a PWA
1. Deploy the `dist/` output to an HTTPS static host.
2. Open the deployed URL on your phone or desktop.
3. Use the browser menu's **Install app** or **Add to Home Screen** option.
4. Open it once while online so the service worker can cache the app. Reopen it to verify offline loading.

## Folder structure
```text
speffz-trainer-pwa/
├── public/
│   └── icon.svg             # App icon
├── src/
│   ├── main.jsx             # React app, training logic, analytics and preferences
│   └── styles.css           # Responsive UI and mobile layout
├── index.html               # HTML entry point and metadata
├── package.json             # Scripts and dependencies
├── vite.config.js            # Vite + PWA manifest/service-worker configuration
├── README.md
└── dist/                    # Generated by npm run build; deploy this folder
```

The service worker and web manifest are generated by `vite-plugin-pwa` from `vite.config.js` during the build; they do not need to be hand-written.

## Training features
- Two color blocks for edges and three for corners; the first sticker is the letter to answer.
- Typing one letter submits automatically; Enter is not required. Physical keyboard-only mode also answers directly from key presses without an input field.
- The preferences **Show side names (Front, Back, etc.)** and **Keyboard-only mode (desktop)** are saved in browser local storage.
- Separate adaptive edge and corner drills prioritize letters with more mistakes/skips and longer response times.
- Session results, per-question times, history, mistake retry, and JSON export.
- PWA manifest and service-worker caching for offline use after first load.

## Exact face configuration
```js
const FACES = [
  { id: "U", name: "Up", color: "#ffffff", letters: "AABBCCDD" },
  { id: "L", name: "Left", color: "#ff7700", letters: "EEFFGGHH" },
  { id: "F", name: "Front", color: "#00ff00", letters: "IIJJKKLL" },
  { id: "R", name: "Right", color: "#ff0000", letters: "MMNNOOPP" },
  { id: "B", name: "Back", color: "#0000ff", letters: "QQRRSSTT" },
  { id: "D", name: "Down", color: "#ffff00", letters: "UUVVWWXX" },
];
```

Repeated letter pairs are intentional and preserved. Training history and preferences stay in the current browser profile; they do not sync across devices.
